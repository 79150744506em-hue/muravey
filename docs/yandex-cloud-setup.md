# Как запустить Муравья в Yandex Cloud

Всё займёт минут 15. Код и автодеплой готовлю я. От тебя нужны аккаунты и ключи, потому что из моей среды нет доступа к Yandex Cloud, а к твоему GitHub я пока не подключён.

## Как это будет работать

- Код лежит в твоём репозитории на GitHub.
- При каждом `git push` в ветку `main` GitHub сам собирает приложение и выкладывает его в Yandex Cloud.
- Сайт открывается по ссылке вида `https://xxxx.apigw.yandexcloud.net` с любого устройства.
- Задачи хранятся в облаке, вход — по email и паролю или через Google.

## Шаг 1. GitHub

1. Создай пустой приватный репозиторий `muravey`: https://github.com/new (без README и .gitignore).
2. Подключи GitHub к Claude: https://claude.ai/connect-github
3. Если GitHub попросит, установи приложение Claude на этот репозиторий: https://github.com/apps/claude/installations/select_target
4. Напиши мне в тред имя репозитория, например `egor/muravey`.

## Шаг 2. Yandex Cloud

1. Зайди в консоль: https://console.yandex.cloud
2. Если аккаунта ещё нет, зарегистрируйся и создай платёжный аккаунт (нужна карта). Новым аккаунтам дают стартовый грант. Муравей укладывается в бесплатные лимиты функций, API-шлюза и хранилища, за месяц выйдет от нуля до нескольких рублей.
3. Открой каталог `default` (он создаётся автоматически). Скопируй его **ID** из шапки страницы каталога, он выглядит как `b1g...`. Это `YC_FOLDER_ID`.
4. Слева выбери **Identity and Access Management → Сервисные аккаунты → Создать сервисный аккаунт**.
   - Имя: `muravey-deploy`
   - Роль в каталоге: `admin`
5. Открой созданный аккаунт → **Создать новый ключ → Создать авторизованный ключ** → алгоритм RSA_2048 → **Создать**. Скачай файл с ключом (JSON). Это `YC_SA_JSON_CREDENTIALS`. Никому его не пересылай, в том числе в этот чат.

## Шаг 3. Секреты в GitHub

В репозитории открой **Settings → Secrets and variables → Actions → New repository secret** и добавь три секрета:

| Имя | Что вставить |
| --- | --- |
| `YC_SA_JSON_CREDENTIALS` | всё содержимое скачанного JSON-файла ключа |
| `YC_FOLDER_ID` | ID каталога, `b1g...` |
| `MURAVEY_PASSWORD` | случайный секрет для подписи ключей входа, например результат `openssl rand -base64 32`; это не пароль от аккаунта |

Когда всё готово, напиши в тред. Я залью код, первый деплой запустится сам, и я пришлю ссылку на сайт.

## Обновления потом

Любое изменение, которое я (или ты) запушу в `main`, через пару минут появится на сайте. Ход деплоя видно во вкладке **Actions** репозитория.
