# Муравей

Таск-менеджер с совместной работой: план на сегодня и бэклог на одной доске, фокусные задачи, теги и комментарии. Продукты содержат таблицу фич с RICE-приоритизацией и оценками команды. Продукты, дорожные карты и карты стейкхолдеров можно открывать другим пользователям по почте на просмотр или редактирование; изменения синхронизируются через CRDT, а приглашения приходят во встроенный центр уведомлений и браузерные пуши. React + Gravity UI, собирается в один `index.html`.

- `src/` — интерфейс.
- `api/` — функция Yandex Cloud Functions: вход по паролю, данные в Object Storage, CRDT-синхронизация и Web Push.
- `deploy/` — спецификация API-шлюза и скрипт деплоя.
- `.github/workflows/deploy.yml` — каждый push в `main` собирает и выкладывает приложение.

Первичная настройка Yandex Cloud и секретов GitHub описана в [docs/yandex-cloud-setup.md](docs/yandex-cloud-setup.md).

Локально: `npm ci && npm run dev` — откроется http://localhost:5173, данные хранятся в этом браузере.
